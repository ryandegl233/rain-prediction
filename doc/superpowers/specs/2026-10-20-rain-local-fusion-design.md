# 降雨任务局部融合：证据、最小设计与验收

状态：用户于 2026-10-20 提供实际标签抽查结果后明确授权开始代码与受控实验。本版实现 A0/R0/R1；空间网格和雨量时间口径审计仍待完成，因此不宣称已修复真实数据对齐。

## 1. 目标和固定边界

目标是提升固定起报的降雨预测，同时避免新融合直接破坏辅助模态预测；检验小范围弱对应容忍是否有价值，而非预设它一定是当前失败原因。

固定原主干、原三个 3D decoder、四历史帧到四未来帧、30 分钟间隔、I/O 优化、残差雨量输出和现有 teacher-forcing/rollout 协议。第一轮保留 A 的 loss、模态系数、固定 q=0.25、数据和增强设置；不同时加入事件损失、结构损失、动态时效权重、跨模态注意力或新生成模型。

baseline、同学代码、既有 A/E 框架和数据保持不变；实现使用独立新文件，禁止 monkey patch。新实验与旧 checkpoint 不混用 resume 状态。

## 2. Gap 与证据等级

| Gap | 当前证据 | 可检验假设 | 反证/停止条件 |
|---|---|---|---|
| 共享输入门控会同时影响辅助预测 | 当前代码结构确定；E 后期雷达门控明显降低 | 将融合增量限定到雨量分支，降低直接前向干扰 | 即使仅改雨量分支也无收益；不能声称解决共享梯度竞争 |
| 同位置融合可能不足以利用局部弱对应 | 用户假设；尚未量化真实空间偏移。原主干已有卷积及注意力，并非完全无邻域能力 | 专用于雨量的局部辅助特征聚合，相比同位置残差融合有额外收益 | 只在人工位移下有效、正常数据无改善；或普通同位置支路效果相同 |
| MSE 改善未带来稳定 CSI 技巧 | A/E 6000 步整体 CSI 均低于 persistence，E 最远时效 MAE 更差 | 后续独立事件/结构目标可改善任务指标 | 虚警增加、只变清晰但位置/雨量错误，或收益来自数据口径改变 |

九个月元数据共 10215 帧，其中雷达来源时间差非零 21 帧（0.206%）、卫星 228 帧（2.232%）。卫星非零差值在 2023 年为 0.285%、2025 年为 6.527%；按本地配置月份划分，训练为 1.502%、验证为 5.900%。这些是原始帧比例，不能代替实际筛选后序列的受影响比例。由于插值来源记录存在歧义，不能直接当成输入的真实观测年龄，也不能据此确认空间偏移。A/E 数据一致，时间差本身不能解释两组表现差异，需检验模型与该因素的交互。数据审计细节见 `doc/experiments/2026-10-20-alignment-data-audit.md`。

## 3. 为什么先采用小卷积支路

备选方案：

1. 直接平均池化或最大池化后融合：适合作为简单容错对照。平均会平滑，最大值可能扩张强信号区域，不应直接替换全部主干信息。
2. 模态独立的 3×3 深度卷积加 1×1 投影，并以残差形式接入雨量分支：作为第一版。保留基础特征，给模型学习局部相关模式的能力，不声称实现逐像素动态配准。
3. 内容自适应卷积核：允许位置和样本相关的权重，但增加可变因素；仅在第 2 项验证了邻域信息价值且仍暴露选择困难后考虑。

动态卷积、局部内容聚合本身已有研究；不作为新的通用算法宣称。参考 [Dynamic Filter Networks](https://proceedings.neurips.cc/paper/2016/hash/8bf1211fd4b7b94528899de0a43b9fb3-Abstract.html) 与 [CARAFE](https://openaccess.thecvf.com/content_ICCV_2019/html/Wang_CARAFE_Content-Aware_ReAssembly_of_FEatures_ICCV_2019_paper.html)。这些论文不证明本项目会获得收益。

第一版不会人为平移云图去贴合雨区，也不会对雷达、卫星和雨量施加像素相等或特征必须相同的损失。

## 4. 第一版的明确计算路径

### 4.1 特征和分支

基础路径采用 A：关闭旧的共享输入乘法门控，主干照常产生待解码特征 `Z`。雷达、卫星 decoder 继续接收 `Z`。

从已有 patch embedding 的雷达、卫星通道权重分别计算模态贡献，复用权重定义；不新建三个完整 backbone。用独立的 1×1 投影把每个模态的贡献降到 32 通道，得到 `V_radar`、`V_satellite`。从 `Z` 投影得到 32 通道的降雨任务查询 `Q`。这只是该位置的预测状态，不是未来雨量标签，也不采用“历史有雨才能融合”的掩码。

空间分支对雷达、卫星分别执行：

```text
U_m = DWConv(k×k, stride=1, same-size padding)(V_m)
D = SiLU(Conv1×1(concat(Q, U_radar, U_satellite)))
DeltaZ = ZeroInitConv1×1(D)
Z_rain = Z + DeltaZ
```

`D` 的通道数为 32。最终投影输出通道数等于 `Z`。最终投影的 weight 和 bias 初始化为零；其他层使用正常可训练初始化，保证增量为零时整个前向复现 A，随后先由最终投影获得梯度。

局部卷积第一版采用独立模态参数、不跨时间卷积。边缘采用 replicate padding，不允许从画面对侧环绕采样；缺失模态的支路输入和支路贡献均按可用性掩码屏蔽。缺失掩码不是干区掩码，雨量为零的区域仍允许辅助信息参与。

雷达、卫星各调用原 decoder 一次，雨量以 `Z_rain` 调用原雨量 decoder 一次。不能先把三个头全部计算后再重算雨量头。decoder 内部结构与参数形状不变。

第一版不设新增可学习门控。现有全局输入门控关闭，新模块靠残差融合和降雨监督学习。这样先回答局部信息是否有价值，避免同时改变邻域聚合和门控机制。

### 4.2 空间尺度

本地配置为输入 448×448、patch_size=8、token 网格 56×56。3×3 kernel 的采样中心覆盖前后一个 token，也就是相对中心最多 ±8 个输入像素；加上每个 patch 的支持区域，整体覆盖更大。它不是 ±1 像素配准。

第一版比较 `k=1` 与 `k=3`，不默认添加 5×5、多尺度金字塔或可变形采样。合成检查采用 0、1、2、4、8 个输入像素位移以报告能力范围，但不得把这些人工位移当成真实数据的实测偏差。实际公里数需由最终网格计算。

### 4.3 时间索引和因果边界

每个预测位置使用其对应 seed 时刻的辅助特征；保留现有时间主干处理历史。原 TF 输入中的重复首位置、rollout 的重复末 seed 必须按明确的索引映射，不把重复位置视为新物理时刻。source 标记沿用真实供给/生成/缺失定义。

不在第一版把分钟级来源时间差当作可学习输入，直到数据审计确认这些时间记录表示真实观测年龄还是插值端点。也不通过整帧向前/向后移动来修正 6 或 10 分钟的差别。

新支路的辅助特征不得读取该位置之后的 seed 或任何目标标签。原 3D decoder 已知的时间 padding/归一化限制保持显式记录；新支路通过因果检查不等于整个旧网络已经因果修复。

### 4.4 梯度和中性复现

新增支路只进入雨量输出，因此它自身的参数通过正常 autograd 接收降雨 loss 梯度；不必再把共享输入门控的梯度人工替换规则套到新增模块上。共享主干及复用的 patch 权重仍受多任务训练影响，必须继续监测。

额外模块初始化使用隔离的随机数状态，不改变公共参数初始化或后续训练随机源。A、同位置支路、局部支路的中性输出需在 FP32 eval 模式精确一致。中性前向一致不保证训练轨迹或最终指标一致。

## 5. 实验如何对应 Gap

### 阶段 0：数据和实现检查

已完成九个月来源时间统计及十帧标签抽查，继续核对时间语义、网格与观测有效性。用户授权先进行现有数据上的受控模型试验，三组保持现用标签完全相同；完整物理归因需等待后续审计。若发现必须修正的数据问题，对所有新比较组一致应用新数据版本，旧 A 不能继续作为直接对照。未经站点有效性确认，不将稀疏 `rain` 直接替换为稠密监督。

新增模块关闭/零初始化时的模型输出一致性、输出头隔离、梯度可达性、缺失掩码、边界行为、TF/rollout 时间索引、checkpoint 恢复先用小模型验证。短训练只能确认实现和资源，不用于宣布方法有效。

### 阶段 1：最小有效性比较

| 组别 | 雨量增量支路 | 空间操作 | 新门控 | loss |
|---|---|---|---|---|
| A0 | 无 | 原模型 | 无 | A |
| R0 | 有 | 1×1 深度卷积 | 无 | A |
| R1 | 有 | 3×3 深度卷积 | 无 | A |

A0→R0 测量增加雨量专用支路的效果；R0→R1 测量额外邻域的效果。R0/R1 只在深度卷积核大小上不同，参数量差异必须报告，不能宣称严格等参数。

已有 A6000 可以作历史参考。正式比较应使用相同数据版本、相同样本顺序/增强随机源、相同训练预算和 checkpoint 规则。如果数据口径或初始化/运行器有所调整，应重跑 A0。

首轮以共同的 6000 optimizer step 为预算，保持现有有效 batch、优化器、学习率和评估频率。只做单一种子时明确标为筛选；候选有收益后再做至少三个预先选定种子的重复，不通过挑最佳种子下结论。

若 R1 比 R0 无改善，不增加动态核或更大窗口来掩盖结果。只有“普通邻域已有价值，但固定聚合仍有可复现选择问题”时才开展动态卷积。

### 阶段 2：任务特定门控与 loss

只有阶段 1 提供支持时才实施：

- 对已聚合辅助特征做降雨分支专用门控；池化可作为生成门控所需的邻域描述，原特征路径保留。
- 门控以预测位置及预测时效、可用性、真实/生成来源为条件；两个模态可同时贡献，不强制权重和为 1。
- 先比较固定增量与自适应门控，保持 loss 不变。
- 再逐项检验雨量事件监督、结构监督，动态时效权重仍单独消融。

这些是后续实验边界，未指定为第一版必须全部实现的模块。

## 6. 指标与成功标准

主要效果报告同一完整验证集、四个时效和整体的 CSI@0.1/0.3/0.5、POD、FAR、MAE、MSE，并同时报告 persistence。当前阈值属于数据尺度，不能未经量纲审计标成 mm/h。

预先以 +120 分钟 CSI@0.3 和全时效 CSI@0.3 为主要比较项，其他阈值及 MAE/POD/FAR 作为必要约束，不只挑某个改善项。候选要在真实验证集同时优于 A0 和 persistence 才能宣称提供了该指标上的预报技巧；若只改善鲁棒性而未超过 persistence，应如实限定结论。

不同窗口可能来自同一天气过程，置信区间采用事件分组或按日期分块的配对重采样；不能把重叠窗口当成独立样本。多随机种子与置信区间共同决定是否推广到长训练。

清晰度用各模态自己的原始场验证，报告空间梯度误差、同尺度图像以及可选的频谱/邻域统计；必须与位置、强度和虚警指标联合看。雨量相对持久性改变量、新生/消散区域分别统计，避免仅复制清晰历史。

人工错位鲁棒性：只扰动输入辅助模态，目标和雨量历史保持不变；使用非循环位移和共同有效内区评价。比较 0 位移与多个幅度下的退化曲线。合成实验有效不能替代正常数据收益。

第一版不保证卫星和雷达更清晰，只保证新增支路不在前向中直接改变它们接收的主干特征；训练后共享参数变化仍可能影响辅助输出，必须测量。

## 7. 文件与资源预算

建议新增：

- `src/rain_local_fusion/fusion.py`：小卷积残差算子。
- `src/rain_local_fusion/model.py`：独立模型子类，保留原前向协议，为雨量 decoder 单独传特征。
- `src/config/ts_rain_train/rain_local_fusion.yaml`：A loss、固定时效权重、独立运行目录和 k 配置。
- `src/tests/rain_local_fusion/`：上述合同与小模型测试。

优先复用 RainPriorityTrainer 的 I/O、loss、rollout 和评估。如果需要额外诊断，在独立子类/脚本实现，不修改 A/E 代码。所有新数据审计工具只读源数据，结果输出到新的诊断目录。

增加的是 token 网格上的 32 通道小支路；不新建完整 backbone，不做全空间 attention，不重复 decoder 前向。24GB RTX4090 上的实际峰值显存、step 时间需要 smoke 实测；不得预先承诺 batch4 或固定速度提升。首轮保持已验收的 batch/梯度累积配置。
